# 小cc 形象方向（三选一）

> 界面与实拍的清单（每张图对应哪一版、是否进对外展示）见文末的「界面实拍清单」一节。

三张稿子都是**同一套协议**下的候选形象，每张含三个状态（待机 / 干活 / 出错），
用来判断一件事：这套造型在三档状态之间切得开不开、可不可爱、像不像「一个活物」。

| 方向 | 形象 | 状态怎么表达 | 优点 | 风险 |
| --- | --- | --- | --- | --- |
| **A** | 星屑小灵「阿星」 | 头顶星芒颜色 + 眼睛 + 光晕深浅 | 最萌、最轻，飘在桌面不抢注意力 | 造型偏抽象，剪影辨识度一般 |
| **B** | 胶囊机甲「丸丸」 | 面罩表情 + 底部呼吸灯环颜色 | 状态一眼可读（灯环是「档位」），做小尺寸最清晰 | 偏科技感，萌度靠细节撑 |
| **C** | 围巾小兽「雪球」 | 围巾颜色 + 围巾飘动幅度 + 耳朵 | 最像「活的」，亲和力强，反差萌（犯错时耳朵耷拉） | 毛绒质感在矢量里较难做得高级 |

配色档位（三方向共用）：

| 状态 | 色 | 含义 |
| --- | --- | --- |
| `idle` | `#6FD3E8` | 待命 |
| `thinking` | `#8FA7FF` | 思考中 |
| `working` | `#FFC24B` | 干活中 |
| `waiting` | `#FF8A5B` | 等你确认 |
| `done` | `#5BD08A` | 搞定 |
| `error` | `#F2665E` | 出错了 |
| `offline` | `#9AA1B1` | 离线 |

> 稿子是**判断方向的草图**，不是最终美术。选定方向后按 `character.json` 的
> 7 状态规范逐帧做精细矢量（透明底、无窗口边框、只在角色自身范围内绘制）。

## 与既有形象的区别（避免雷同）

- 不是鱼/鲸类造型，剪影、配色、动作体系全部重做；
- 不引用任何第三方美术资源：全部矢量稿为本项目原创，由 Codex CLI 按书面几何规格
  程序化生成后人工校对坐标（生成规格与校对留档见 `docs/design/生成记录.md`），可随 MIT 一起发布；
- 状态表达不靠「换整张图」，靠**同一个身体 + 光/表情/附属物**的变化，
  所以新增状态不需要重画一张图（这也是可扩展性的一部分）。
## 界面实拍清单（文件 ↔ 版本 ↔ 状态）

这张表是 `docs/design/` 里每个文件的唯一挂点：图在这里被引用，才不会变成「读者找不到、作者也不记得它对应哪一版」的孤儿。
新增一张图就往表里加一行。`scripts/release_check.py` 的第二条判据就是按这张表查「`docs/` 下的图有没有人引用」，
所以表里漏写一张，判据会当场报出来。

**数据口径**：额度与账本那几行是**替身数据**（`scripts/make_shot_fixtures.py` 造的假报告，不是作者真实调用次数/金额）；
**设备那几行是拍摄机的真实读数**（CPU/内存/磁盘/电池没有替身缝），不含身份信息。
「含桌面像素=否」这一列只对这 13 张负责断言 —— 历史图那列留空，不猜。

> 这条列现在**不再是逐张眼验出来的**：11 张实拍全部走**窗口级**抓图（`how ∈ {window, window-composite}`，
> 合成用 CoreGraphics、不引 PIL），拍摄脚本里根本不调用「连桌面一起截」那条路 ⇒ 「不含桌面像素」是**结构性保证**。
> 淡化三帧每轮选帧有 ±0.2 的 α 抖动，所以表里只给端点与「介于中间」，不给中间帧写死数 ——
> 给采样时刻定阈值等于给快门定阈值。

**这些图怎么重拍的**（可复现）：
```bash
.venv/bin/python scripts/make_shot_fixtures.py --out "$HOME/.xiaocc-shots" --hermes-dir "$HOME/.hermes-demo"
.venv/bin/python scripts/shoot_design_shots.py --out docs/design --evidence "$HOME/.xiaocc-shots/design-shots.evidence.json"
```
第一条造替身数据（假额度报告 / 假账本，四个沙箱缝指过去）；第二条开真窗口逐张拍，并在落盘前
对每张做三件事：**几何**（取景框必须落在衬底内）、**像素**（`bright_px == 0`、`colors ≤ 4`）、
**红线**（落盘文本里不许出现本机家目录绝对路径）。拍法字段 `how` 由抓图路径自己盖，
`window` = 只抓窗口本体、`window-composite` = 抓窗口再合成到中性底（**右键菜单与贴边把手条走这条，
因为它们只能叠在桌面上，而桌面内容不许进公开仓库**）。

### 三、已退役（不留在工作树，永远可解析）

这一节是 16 张退役图的**索引**：它们记录了「当时的界面长什么样」和「哪个 bug 被修过」，
所以名字、退役原因、以及「哪一版里有它」都留在这一节。图本身不在工作树里（checkout 因此少 5.35MB），
但它们在**历史**里，一条命令取回：

```bash
git show <下表那一列的提交>:docs/design/<文件名> > /tmp/<文件名>
```

`git rm` 删掉的是工作树与后续版本，**动不了 pack** —— 只要那一版还在，这些图就取得回来。
所以这一节现在给的是**指针**（名字 + 退役原因 + 提交）：哪天有人问「这张图怎么和界面对不上」，
