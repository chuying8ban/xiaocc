# 丸丸 · 资产说明

小cc 的正式形象是「方向 B · 胶囊机甲丸丸」：圆角胶囊身 + 深色面罩 + 底部灯环，
状态靠「面罩表情 + 灯环形色 + 姿态」区分。

## 1. 形象定位

- 主体：圆角胶囊身（白色金属渐变），正面一块深色面罩承载表情。
- 灯环：面罩下方一条胶囊形灯带，颜色随状态变化，是状态的第一识别信号。
- 姿态：手臂、附件（扳手 / 星星 / 火花线）与整体倾斜用于补强状态语义。
- 识别尺寸：最小 60px 显示，所有表情线条按此校核线宽。

## 2. 造型来源

几何取自本项目 `docs/design/方向B-胶囊机甲丸丸.svg`。该文件是当初方向 A / B / C
三选一时的概念稿，只含 idle / working / error 三档；三张方向稿都是本项目原创，
由 Codex CLI 按同一份书面几何规格程序化生成，再人工校对，以 MIT 发布
（生成方式与逐文件来源见 `docs/design/生成记录.md`）。

正式稿在它的基础上做了两件事：

- 等比缩放重排进 `132×140` 画布，身体与面罩的相对比例保持不变；
- 把状态补全到 7 个（见第 4 节对照表），新增状态沿用同一套几何，只改 accent 色、
  面罩表情与附加元素。

## 3. 生成方式

7 个 SVG 由 Codex CLI（`codex exec`）按同一份几何规格逐文件生成，
人工校对了坐标与画布边界：`waiting` 的手臂、`idle` 的嘴弧弧向都在校对中修正过。

生成时使用的规格文本等价于提示词，已留档在第 5 节的表里；新增状态时照抄该表，
再补上该状态的表情与 accent 即可复现同一套画风。逐文件来源与校对点另见
[生成记录.md](生成记录.md)。

## 4. 文件与状态对照表

源文件位于 `src/xiaocc/characters/*/<角色目录>/assets/`，下表按状态列出。

| 状态 | 文件 | accent | 面罩表情 | 姿态或附加元素 |
| --- | --- | --- | --- | --- |
| idle | `assets/idle.svg` | `#6FD3E8` | 一道上扬的嘴弧 | 两手自然下垂 |
| thinking | `assets/thinking.svg` | `#8FA7FF` | 三个点 | 一只手抬到面罩旁 |
| working | `assets/working.svg` | `#FFC24B` | `>` `>` 尖括号 | 举手拿扳手 + 小火花 |
| waiting | `assets/waiting.svg` | `#FF8A5B` | 大感叹号 | 一只手向外招 |
| done | `assets/done.svg` | `#5BD08A` | 两道 `^` 笑眼 | 两侧小星星 |
| error | `assets/error.svg` | `#F2665E` | 两个 `×` | 头顶火花线，整组倾斜 -5° |
| offline | `assets/offline.svg` | `#9AA1B1` | 一道横线（闭眼） | 整身灰调、灯珠熄灭 |

accent 即第 5 节 `glow` 渐变的起始色，同时用于灯环与天线灯珠。

## 5. 共用几何规格

| 要素 | 规格 |
| --- | --- |
| 画布 | `viewBox="0 0 132 140"`，透明背景（不铺底色 rect） |
| 组变换 | 全部可视元素包在 `translate(66 80) scale(0.94)` 的 `<g>` 内 |
| 渐变 `shell` | `#FFFFFF` → `#EEF1F7` → `#D3DAE8`（身体金属感） |
| 渐变 `visor` | `#2A3242` → `#171C26`（面罩深色） |
| 渐变 `glow` | accent `0.5` → accent `0`（灯环 / 灯珠外发光） |
| 身体 | `rect x="-38" y="-44" width="76" height="88" rx="34"` |
| 面罩 | `rect x="-28" y="-26" width="56" height="34" rx="16"` |
| 灯环 | `rect x="-22" y="22" width="44" height="7" rx="3.5"` |
| 天线 | `path d="M0 -44 v -12"` + 灯珠 `circle cy="-59" r="5.5"` |
| 表情线宽 | 3.6 ~ 4.4，保证缩到 60px 仍看得清 |
| 边界 | 所有元素必须落在画布内（含 `error` 倾斜 -5° 之后的包围盒） |

渐变 id 固定为 `shell` / `visor` / `glow`，便于跨文件替换 accent 时统一处理。

## 6. 许可

- 与本项目代码同为 **MIT**（见仓库根目录 `LICENSE` 与 `ASSET_LICENSE.md`）。
- 明确不引用任何第三方角色素材，尤其 `dsh-dafeiyu` / `dsh-pet` 的角色帧、图标、光标。
- 也不建议拿这些图去描摹第三方形象；派生创作请从第 5 节的几何规格出发。

## 7. 怎么加新状态

照第 5 节的几何规格新建 `assets/<state>.svg`，
在 `character.json` 的 `states` 与 `assets` 里各加一条即可，显示层不用改。
